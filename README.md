# Kawser Ahamad - Software Engineer Portfolio

A modern, responsive personal portfolio website built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, and **DaisyUI v5**. Designed to highlight full-stack projects, core computer science background, and competitive programming achievements.

---

## 🌟 Key Features

- 🌓 **Dark & Light Mode Toggle**: Interactive theme switcher with persistent user preference stored in `localStorage`.
- 🚀 **Featured Projects Showcase**: Project cards featuring live demo links, GitHub repositories, tech stack badges, and optimized preview image banners.
- 📱 **Fully Responsive Layout**: Built with a mobile-first approach using Tailwind CSS and DaisyUI components.
- ⚡ **Optimized Performance**: Pre-rendered static pages using Next.js App Router for maximum speed and instant page loads.
- 🏆 **Competitive Programming Highlight**: Dedicated section detailing C++ problem-solving and Codeforces profile integration.

---

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/kawser0x/Protfolio.git
   cd Protfolio
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Run the development server**:

   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application live.

---

## 🛠️ Build & Scripts

- `npm run dev`: Starts the Next.js development server.
- `npm run build`: Compiles an optimized production build.
- `npm run start`: Launches the production server.
- `npm run lint`: Runs ESLint checks across the codebase.
